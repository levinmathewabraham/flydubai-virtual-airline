# vFDB React Website

The official website for vFDB Virtual Airline, a Flydubai-inspired virtual airline for flight simulation pilots.

## Tech Stack

- React
- Vite
- Bootstrap 5
- JavaScript (JSX)
- Custom CSS animations

# Getting Started

## Prerequisites

- Node.js
- npm

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

The website uses a single-page layout with reusable React components.
Bootstrap and custom CSS handle responsive styling.
Never commit secrets, credentials, or private environment configuration to the repository.
