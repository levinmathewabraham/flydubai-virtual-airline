# vFDB React Website

A React + Vite + Bootstrap website for vFDB Virtual Airline.

## Stack

- React
- Vite
- Bootstrap 5
- JavaScript (JSX)
- Custom CSS animations

## Sections

- Home
- About vFDB
- Fleet
- Route Network
- Pilot Center
- Documents
- FAQ
- Partners
- Community

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
